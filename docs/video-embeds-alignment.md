# Video embeds and content alignment

## Plan and scope

This feature depends on the inline-image editor work in PR #96. The implementation
branch starts from `develop` and includes that pending prerequisite. Merge #96 first.

1. Reuse the official Tiptap YouTube and TextAlign extensions and shared document schema.
2. Add insert/edit/remove video controls and selection-aware alignment controls.
3. Keep saved documents, editor views, sanitized articles and previews consistent.
4. Verify URL validation, rendering/CSP, persistence, Undo and responsive interaction.

## Authoring behavior

The video dialog accepts YouTube watch, share, Shorts and embed links. It stores a
canonical privacy-enhanced YouTube embed URL, a descriptive player title and supported
start time. It does not accept arbitrary iframe HTML or other video providers.
Playback is controlled by the reader, without autoplay. Authors can edit or remove
an existing video block. Inserting a video leaves a paragraph ready for further typing.
Video frames support proportional corner dragging and keyboard resizing. The dialog's
Full content width option fills the current content container, with automatic height.
Resizing to a specific width turns full-width mode off; width, height and full-width
mode are saved with the block and remain responsive on smaller screens.

Left, Center, Right and Justify apply to text blocks, including paragraphs and headings.
Images and videos support Left, Center and Right; Justify is unavailable for selected
media because it describes text spacing. Alignment is saved in document attributes.
Media alignment moves the block within its container and does not float text around it.
Existing documents retain their current default alignment.

## Rendering and policy

The editor and article renderer share the same extensions. Only known alignment values
survive rendering; arbitrary inline styles remain disallowed. Video sources are validated
again when rendering saved content. Trusted iframe attributes are generated by the app,
with a title, responsive dimensions, lazy loading and a referrer policy suitable for
YouTube playback. Saved dimensions are validated and used to generate sizing markup;
authored style strings are discarded. The Worker CSP permits frames only from the exact privacy-enhanced
YouTube host. Images retain their resize dimensions and fit narrower containers.

Changing rendered-media policy increments the rendered-article cache version. No SQL
schema or upload lifecycle changes are required for these document attributes.

## Verification

Unit tests cover supported/rejected URLs, unsafe saved content, alignment validation,
trusted iframe attributes, CSP and unchanged image/text rendering. Browser tests cover
insertion, editing/removal, Undo, alignment, Save payloads, accessibility and mobile bounds.
Run `npm run check`, the affected editor browser suites and the local upload regression
suite before shipping. Documentation describes supported providers and controls.
